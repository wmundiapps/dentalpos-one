# 担保人与押金

版本 2026-09-24 · 自2026年9月24日起生效

## 1. 目的

1.1. 本文件为《使用条款》的组成部分,规范可能伴随某次预订出现的两种担保方式:**押金**(在租用方支付方式上进行的预授权)和**担保人**(为租用方财务义务提供担保的人)。

1.2. 该等担保仅用于弥补租用方因该次预订而产生的应付款项:损坏赔偿、额外清洁费、退场延迟费用、物业管理罚款以及依《处罚与措施》裁定的处罚,以及未付清的价款余额。

## 2. 押金

2.1. **定义。** 押金是对租用方信用卡或支持该操作的支付方式所作的**预授权**(临时冻结额度)。除非有事件裁定不利于租用方,否则该金额不会被扣款。

2.2. **金额。** 押金金额由空间提供方在房源信息中设定,**不得超过**该次预订**基础价值的3倍**。若设定金额超过该上限,以上限为准。

2.3. **时点。** 预授权在预订确认时或第一个预订时段开始前进行,具体取决于发卡机构允许的有效期,并可在包含多个预订时段的预订中续期。

2.4. **释放。** 若在最后一个预订时段退场登记后**72小时内**无未结事件,押金即予释放。若在此期间存在未结事件,与索赔金额对应的部分继续冻结直至裁定作出,其余部分予以释放。

2.5. **扣款。** 只有经租用方认可或经平台依《争议解决中心》文件裁定的金额方可被扣取。租用方将收到所扣金额的明细说明。

2.6. **发卡机构处理时间。** 平台释放后,额度的解冻可能需要几天时间,具体取决于发卡机构。

## 3. 不支持预授权的支付方式

3.1. **Pix、代收单(boleto)、OXXO、SPEI、Multibanco、便利店代收(konbini)、银行转账、BPAY、PSE、网上银行、UPI、Bizum、MB WAY、Bit、PayID及Yape**等支付方式不支持预授权。

3.2. 当房源信息要求押金而租用方使用上述支付方式之一时,押金须由租用方选择以下之一予以替代:(a) 仅用于押金预授权而单独注册的**担保信用卡**;或 (b) 依本文件规定接受的**担保人**。

## 4. 担保人——要求情形

4.1. 空间提供方在房源信息中设定以下政策之一:

| 政策 | 效果 |
|---|---|
| **不要求**(`none`) | 不要求提供担保人。 |
| **可选**(`optional`) | 租用方可指定担保人,以为空间提供方提供更高保障,这可能有助于申请制预订获得批准。 |
| **强制要求**(`required`) | 所有预订均须有已接受的担保人。 |
| **超过一定金额时强制要求**(`required_over_amount`) | 当预订总额达到或超过空间提供方设定的限额时,要求提供担保人。 |

4.2. 对担保人的要求不得作为歧视工具使用。须对该房源信息的所有租用方统一适用。

## 5. 担保人——信息、接受与期限

5.1. 租用方须提供:姓名全名、电子邮箱、电话(可选)、身份证件号码以及与租用方的关系(可选)。租用方声明已获得担保人授权,可为此目的将该等信息分享给平台。

5.2. 担保人通过发送至其电子邮箱的**个人专属安全链接**收到邀请,内容包括:租用方、空间及各预订时段的身份信息;预订总额;责任限额;以及本文件的完整内容。

5.3. 担保人有 **48小时** 时间接受或拒绝。在收到回复之前,预订状态为"等待担保人确认",款项仅处于授权状态。担保人拒绝或逾期未回应的,申请终止,授权款项全额释放,不产生任何费用。

5.4. 担保人可以**自由拒绝**,无需说明理由,且不对其本人产生任何后果。

5.5. 担保人须**年满18周岁**(或所在国规定的更高最低年龄,例如阿拉伯联合酋长国为21周岁)并具备完全民事行为能力。法人可通过有权代表担任担保人。

## 6. 担保人——责任

6.1. 担保人接受后,即就该次预订所产生的应付款项与租用方**承担连带责任**,**以该次预订总额的3倍为限**,或以邀请中载明的更低金额为限。

6.2. 担保人的责任:(a) 仅针对单一预订及其各预订时段;(b) 不涵盖其他预订,也不涵盖非金钱性义务;(c) 仅在依《处罚与措施》文件规定的收款顺序、经尝试通过押金及租用方支付方式收款未果后方可启动;(d) 当该预订在报告期限内未产生未结事件而顺利完成,或已裁定金额已全额支付时,自动终止。

6.3. 担保人将就可能对其产生追责的事件登记收到通知,并可在给予租用方的相同48小时期限内提出意见,亦可对裁决提出申诉。

6.4. 已付款的担保人有权就其已支付的全部金额向租用方追偿。

6.5. 在巴西,该担保具有《民法典》第818条及以下条款规定的有限约定保证(fiança convencional limitada)的法律性质,明确约定连带责任并放弃顺序利益(第828条第一款及第二款),但不影响平台承诺遵守的第6.2条(c)项规定的操作性收款顺序。担保人已婚的,如适用,须满足配偶共同签署的法定要求。在其他国家适用相应的担保制度(如"guarantee"、"fianza"、"Bürgschaft"、"cautionnement"),并遵循当地形式要求。

## 7. 担保人的数据保护

7.1. 担保人数据的处理依据担保合同的履行,以及平台与空间提供方在保障预订方面的合法利益,并遵守《通用个人数据保护法》(LGPD)及《各国规则》文件中列明的相应法律。

7.2. 该等数据仅用于:发送邀请、记录接受情况、身份核实、事件相关沟通及收款事宜。未经特别同意,不得用于营销目的。

7.3. 空间提供方仅能查看担保人姓名及接受状态。证件及联系方式仅在司法或非司法追偿所必需时与空间提供方共享。

7.4. 拒绝或未回应的担保人数据将在90天内删除,法律另有规定的除外。已接受的担保人数据将保留至受担保义务的时效期届满。担保人可通过《隐私政策》中载明的负责人渠道行使其数据主体权利:**[ENCARREGADO/DPO]**。

## 8. 最终规定

8.1. 押金与担保人可在同一预订中并存。担保方式的存在不限制租用方的责任,租用方仍须对其造成的损害承担全部责任。

8.2. 平台并非租用方对空间提供方所负义务的担保人,除非平台以书面形式在特定项目中提供额外保障。
