# 评价政策

版本 2026-09-24 · 自2026年9月24日起生效

## 1. 目的与宗旨

1.1. 本文件为《使用条款》的组成部分,规范平台上发布的评价,其目的在于基于真实体验建立空间提供方与租用方之间的信任。

1.2. 评价分为三种类型:
- (a) **租用方对空间及空间提供方的评价**;
- (b) **空间提供方对租用方的评价**;
- (c) **终端客户对空间的评价**——**可选**工具,仅在租用方要求时开启。

## 2. 谁可以评价及期限

2.1. 只有已完成预订(已退场登记或最后一个预订时段已结束)的双方可以互相评价,每次预订限一次。

2.2. 评价期限为预订结束后 **14天** 内。

2.3. 每份评价包含1至5星的总体评分、按各项标准打出的1至5分评分,以及一段 **10至2000字符** 的公开评论。此外还可包含给对方的私密评分,该私密评分不予公开。

## 3. 评价标准

3.1. **租用方对空间及空间提供方的评价:**

| 标准 | 评价内容 |
|---|---|
| 清洁度 | 到达时空间的卫生状况 |
| 准确度 | 房源信息与实际情况的相符程度 |
| 设备 | 房源信息中所述设备的齐全性、运行状况及维护情况 |
| 位置 | 该地址的可达性、安全性及便利性 |
| 沟通 | 空间提供方沟通的清晰度与及时性 |
| 性价比 | 价格与体验的匹配程度 |

3.2. **空间提供方对租用方的评价:**

| 标准 | 评价内容 |
|---|---|
| 准时性 | 是否按预订时间到达和离开 |
| 爱护程度 | 对空间及设备的维护与清洁情况 |
| 规则遵守 | 对空间、建筑物及平台规则的遵守情况 |
| 沟通 | 沟通的清晰度与礼貌程度 |
| 是否推荐 | "是/否"表示是否会将该租用方推荐给其他空间提供方 |

## 4. 双盲评价

4.1. 空间提供方与租用方之间的评价采用**双盲**方式:任一方在提交自己的评价之前均无法看到对方的评价。两份评价在双方均完成评价后,或14天期限届满时(以先发生者为准)同时公开。

4.2. 评价发布后,作者不得自行修改,但可向平台申请更正明显笔误。

## 5. 公开回复

5.1. 被评价方可就收到的每份评价发布**一条公开回复**,须遵守相同的内容规则。回复须客观,不得含有人身攻击或第三方个人数据。

## 6. 终端客户评价(可选)

6.1. **开启。** 租用方可以**自愿**为某次预订开启收集终端客户对空间评价的功能。空间提供方不得要求该功能开启。

6.2. **邀请。** 租用方生成**一次性使用链接**,每个链接有效期为 **14天**,每次预订最多 **50个邀请**,并以其自行选择的方式交付给终端客户。平台不为此目的获取终端客户的联系信息。

6.3. **匿名性。** 终端客户的评价是**匿名的**:无需注册,不显示姓名或身份信息,作者仅可选填一个可选的昵称。

6.4. **评价标准。** 终端客户仅就**空间**本身进行评价,标准为:**舒适度、清洁度、无障碍程度及位置**。不对专业人员(租用方)、服务态度或所接受的治疗进行评价。

6.5. **禁止健康数据。** **严禁**在终端客户评价中包含**健康数据、诊断信息、治疗方案、诊疗操作**、姓名、证件信息、联系方式或任何可识别患者、客户身份或就诊原因的信息。评价表单显示该提示,违反本规则的评价将被删除。

6.6. **职业保密义务。** 租用方须依据其职业道德规范,自行判断交付邀请是否与诊疗保密义务相符(例如心理咨询领域),并对该决定承担唯一责任。链接的交付不得以获得任何好处为条件,也不得以暴露患者身份的方式进行。

6.7. **展示。** 终端客户评价单独展示,并标明其来源,构成该空间独立的评价指标。

## 7. 内容规则

7.1. 评价须诚实、基于真实体验并与该次预订相关。禁止以下内容:
- (a) 含有第三方个人数据、健康数据或保密信息;
- (b) 具有歧视性、冒犯性、猥亵、威胁性质或构成骚扰;
- (c) 含有仇恨言论或煽动暴力;
- (d) 含有广告、外部链接或联系方式;
- (e) 涉及与该次预订无关的事实或未参与的第三方;
- (f) 故意虚假或具有误导性。

## 8. 虚假评价、购买评价与敲诈

8.1. 禁止以下行为:(a) 未参与该次预订而进行评价;(b) 以评价或撤除评价为条件提供或接受付款、折扣、退款或其他利益;(c) 制造虚构预订以产生评价;(d) 使用多个账户;(e) **以发布负面评价相威胁获取利益**(敲诈),或对提起合法事件登记的一方进行负面评价报复;(f) 生成终端客户邀请并由本人或未接受服务的人员自行填写。

8.2. 上述行为构成严重违规,行为人将被记录警告,并视情况予以除名,相关评价亦将被删除。

## 9. 审核与删除

9.1. 平台不编辑评价内容,但可**删除**违反本文件、法律或司法裁决的评价(全部或部分),或对因欺诈被取消的预订所关联的评价予以隐藏。

9.2. 任何用户均可通过平台举报某条评价。审核在合理期限内完成,如予删除将通知作者,作者可提出申诉。

9.3. 平台不会仅因评价为负面而将其删除。存在分歧的应通过公开回复处理。

9.4. 与存在未结事件的预订相关的评价可保持隐藏状态直至裁定作出,以避免报复。

## 10. 评价的使用

10.1. 平均评分根据已发布的评价计算,并展示在个人主页及房源信息中。评价可能被纳入搜索结果排序及认可计划的考量因素。

10.2. 依据透明度相关规定(例如欧盟《数字服务法》及消费者保护法律),平台说明:只有实际已完成预订的当事方及持有有效邀请链接的终端客户方可进行评价。
