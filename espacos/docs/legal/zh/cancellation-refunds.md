# 取消与退款政策

版本 2026-09-24 · 自2026年9月24日起生效

## 1. 一般规定

1.1. 本文件为《使用条款》的组成部分,规定租用方、空间提供方取消预订或因减责事由取消预订的后果,以及退款的期限和方式。

1.2. 每项房源信息采用三种取消政策之一——**灵活型**、**适中型**或**严格型**——并在房源信息及付款前的预订摘要中予以展示。适用的政策以预订当时有效的政策为准。

1.3. 各期限均以取消在平台上登记的时刻起,至**每个预订时段开始**为止,按空间时区计算的小时数计算。

1.4. 各政策的百分比适用于每个预订时段的**基础价值**。清洁费、服务费及服务费所涉税款,依第5条和第6条的具体规则处理。

1.5. 本文件的规定不影响法律强制赋予租用方消费者的更有利权利,该等权利始终优先适用。

## 2. 适用顺序

2.1. 在处理租用方发起的取消时,平台按以下顺序进行核查:
- (a) **宽限期**(第3条)——全额退款;
- (b) 空间所在国的**后悔权**(第4条)——全额退款;
- (c) 房源信息的**取消政策**,按预订时段逐一核算(第5条)。

2.2. 减责事由(第8条)及空间提供方取消(第7条)另有专门规则。

## 3. 宽限期

3.1. 若预订至第一个预订时段开始时**至少提前48小时**作出,且尚无任何预订时段已开始,则租用方可在**预订确认后24小时内**取消并获得**全额退款**(基础价值、清洁费、服务费及税款)。

3.2. 宽限期适用于所有国家的所有租用方,无论其是否为消费者。

## 4. 后悔权

4.1. 符合消费者身份的租用方,在**尚无任何预订时段已开始**的前提下,可自预订之日起,在空间所在国规定的后悔期内撤销预订,并获得已付全部款项的**全额退款**。

4.2. 平台参数化设置的期限如下:

| 国家 | 期限 | 参考依据 |
|---|---|---|
| 巴西 | 7天 | 《消费者保护法典》(CDC,第8,078/1990号法律)第49条 |
| 阿根廷 | 10天 | 第24,240号法律第34条 |
| 智利 | 10天 | 第19,496号法律(远程购买撤回权) |
| 哥伦比亚 | 5天 | 2011年第1480号法律(撤回权) |
| 乌拉圭 | 5天 | 第17,250号法律 |
| 哥斯达黎加 | 8天 | 第7472号法律 |
| 萨尔瓦多 | 8天 | 《消费者保护法》 |
| 墨西哥 | 5天 | 《联邦消费者保护法》 |
| 葡萄牙、西班牙、意大利、法国、德国 | 14天 | 欧盟关于远程合同的立法及各国转化立法 |
| 英国 | 14天 | 《2013年消费者合同条例》(Consumer Contracts Regulations 2013) |
| 以色列 | 14天 | 《1981年消费者保护法》(第5741号) |
| 其他服务国家 | 未参数化 | 适用宽限期、房源信息政策及当地可能存在的法定权利 |

4.3. 在平台上,该期限自预订时刻起以自然日计算。当当地法律规定以工作日计算或规定更长期限时(例如哥伦比亚、乌拉圭及墨西哥的"5个工作日"),经争议解决中心申请,适用对消费者更有利的法定计算方式。

4.4. 在某些法域(例如欧盟及英国),法律允许就特定日期提供的服务排除撤回权。平台出于自愿,在上表所列期限内向消费者授予该权利,但始终以第一个预订时段开始前为限。

4.5. 当当地法律不将出于专业目的进行预订的租用方视同消费者时,后悔权不适用于该等租用方;此类租用方适用宽限期及房源信息政策。

## 5. 租用方取消政策

5.1. 在宽限期和后悔期之外,每个未来预订时段依取消时刻与其开始时刻之间的提前量单独评估:

**灵活型政策**

| 距预订时段开始的提前量 | 基础价值退款比例 |
|---|---|
| 24小时及以上 | 100% |
| 不足24小时 | 50% |

**适中型政策**

| 距预订时段开始的提前量 | 基础价值退款比例 |
|---|---|
| 72小时及以上 | 100% |
| 24小时至不足72小时 | 50% |
| 不足24小时 | 0% |

**严格型政策**

| 距预订时段开始的提前量 | 基础价值退款比例 |
|---|---|
| 168小时(7天)及以上 | 100% |
| 72小时至不足168小时 | 50% |
| 不足72小时 | 0% |

5.2. **系列预订中按时段退款。** 对于包含多个预订时段的预订(连续天数或每周重复),基础价值在各预订时段间平均分配,每个未来预订时段按其自身的提前量获得相应比例的退款。已开始或已完成的预订时段不予退款。

5.3. **清洁费。** 任何尚未开始即被取消的预订时段的清洁费,**始终全额退还**,不论适用何种政策,因为清洁服务将不再进行。

5.4. **服务费及税款。** 租用方服务费及其税款按**获得基础价值全额退款(100%)的预订时段数量**占该次预订全部预订时段总数的比例退还。获得50%或0%退款的预订时段不产生相应服务费的退还。

5.5. **示例。** 一个包含4个预订时段的每周系列,采用适中型政策,在距第一个时段开始还剩30小时时取消。第一个预订时段按比例获得基础价值的50%;后三个时段(提前超过72小时)获得100%。4个预订时段的清洁费全额退还。服务费及税款按3/4比例退还。

5.6. **未到场。** 未取消且未到场的情形,不产生该预订时段基础价值或服务费的退款。若空间提供方确认无需清洁,未使用的清洁费予以退还。

5.7. **提前离场。** 在预定时间之前结束预订时段,不产生未使用时长的退款。

## 6. 可退款项目汇总

| 项目 | 宽限期/后悔权 | 房源信息政策 | 空间提供方取消 | 未到场 |
|---|---|---|---|---|
| 基础价值 | 100% | 按对应区间,逐预订时段计算 | 100% | 0% |
| 清洁费 | 100% | 未开始的预订时段100% | 100% | 若无需清洁则退还 |
| 租用方服务费 | 100% | 按获得100%的预订时段比例 | 100% | 0% |
| 服务费税款 | 100% | 按获得100%的预订时段比例 | 100% | 0% |

## 7. 空间提供方取消

7.1. 空间提供方须履行已确认的预订。若由其取消,租用方就被取消的预订时段获得已付全部款项的**100%退款**,平台将尽力为其推荐类似空间。

7.2. 此外,空间提供方须承担以被取消预订时段基础价值为计算基础的罚款,该罚款从未来转账中扣除或通过其注册的支付方式收取,并记录一次警告:

| 距预订时段开始的提前量 | 对空间提供方的罚款 | 警告 |
|---|---|---|
| 168小时(7天)及以上 | 0% | 是 |
| 48小时至不足168小时 | 10% | 是 |
| 不足48小时 | 25% | 是 |

7.3. **12个月内由空间提供方发起的取消达3次**,将依《处罚与措施》文件规定导致空间提供方账户被**暂停**。空间提供方还可能被系统锁定被取消的日期,并在搜索结果中失去优先展示地位。

7.4. 当取消系因经核实的减责事由(第8条)或租用方经妥当报告的严重违规所致时,不适用罚款及警告。

## 8. 减责事由与不可抗力

8.1. 减责事由指预订之后发生的、不可预见或不可避免、致使预订无法履行的事件,例如:自然灾害;主管当局对不动产或建筑物实施的查封或禁用;空间长时间停电或断水;伴有官方限制措施的传染病疫情;租用方、空间提供方或其近亲属突发死亡或重病;司法、选举或兵役征召;致使空间无法使用的严重损坏。

8.2. 若通过争议解决中心在取消后14天内提交适当文件(证明、当局文书、警方记录、鉴定报告)证实该等情形,租用方就受影响的预订时段获得**全额退款**,空间提供方不受罚款或警告处理。

8.3. 以下情形不构成减责事由:日程变更、终端客户缺席、常见天气状况、可预见的交通问题,或预订时已知的既有义务。

## 9. 退款期限与方式

9.1. 退款一经决定,平台立即处理,并尽可能通过原支付方式退还:

| 支付方式 | 预估期限 |
|---|---|
| 信用卡或借记卡、数字钱包(Apple Pay、Google Pay、PayPal、支付宝、微信支付等) | 视发卡机构而定,5至10个工作日;可能体现在下一期账单中 |
| Pix、银行转账、SPEI、SEPA、ACH、Interac、UPI、PayID及类似方式 | 最长5个工作日 |
| 代收单(boleto)、OXXO、便利店代收(konbini)、Multibanco及其他无法识别来源账户的支付方式 | 转入租用方指定的银行账户,自指定后最长5个工作日内完成 |
| 尚未扣款的授权(申请制预订或押金) | 平台立即释放;解冻所需时间取决于发卡机构 |

9.2. 以外币退款可能受发卡机构适用的汇率波动影响,运营方对此不具有控制权。

9.3. **可选积分。** 租用方可选择不接受退款,而改为获得等值的平台积分,该积分可在12个月内使用。积分选项绝不强制,以现金方式退款的选项始终获得保障。

## 10. 最终规定

10.1. 租用方因事件(见《处罚与措施》)而产生的应付款项,经详细说明后,可与待退款项相抵销。

10.2. 对退款计算的疑问或异议可通过争议解决中心提出。
