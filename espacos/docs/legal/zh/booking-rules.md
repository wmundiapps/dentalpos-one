# 预订与使用规则

版本 2026-09-24 · 自2026年9月24日起生效

## 1. 目的与宗旨

1.1. 本文件为《使用条款》的组成部分,规定预订在平台上如何发起、确认和使用。首字母大写的术语具有《使用条款》中赋予的含义。

1.2. 平台的存在是为了实现**按小时、班次或天数、对处于闲置时段的现成空间的共享使用**。平台不是用于订立持续占用、长期租赁、企业住所或居住用途的工具。

1.3. 本文件规定的各项限制由系统在预订时自动执行,**空间提供方与租用方之间的约定不得排除适用**。这些限制的目的在于:(a) 维持对配备设施空间的临时使用许可的法律性质,避免被认定为租赁关系并避免产生商业场所权或续约权(在巴西为第8,245/1991号法律,在其他国家为相应规定);(b) 保证多位专业人士对空间的轮换使用与获取机会;(c) 保护空间提供方免受占有或永久占用主张的影响。

## 2. 时间与时长限制

2.1. 以下限制适用于所有预订:

| 参数 | 规则 |
|---|---|
| 时间颗粒度 | 起止时间须为 **30分钟** 的整数倍(例如08:00、08:30、09:00) |
| 每个预订时段最短时长 | **1小时**,或空间提供方在房源信息中设定的更高最低值 |
| 每个预订时段最长时长 | **12小时** |
| 允许时间段 | 空间时区内的 **06:00** 至 **23:00** 之间 |
| 过夜 | **禁止**——每个预订时段须在同一天内开始和结束 |
| 连续天数 | 同一预订最多 **连续5天** |
| 每周重复 | 每个系列最多 **12周**(同一星期几) |
| 每次预订的预订时段数 | 最多 **12个** |
| 最长提前预订时间 | 自空间时区当前日期起 **180天** |
| 最短提前预订时间 | 预订时段开始前 **1小时** |
| 时长上限 | 同一租用方就同一空间,在任意 **30天** 滚动窗口内 **120小时** |
| 有效的重复系列数 | 同一租用方就同一空间最多同时存在 **2个** 系列 |
| 最长系列结束后的间隔 | 在同一空间开始新系列前,须在12周系列结束后间隔 **14天** |

2.2. **允许的模式。** 包含多个预订时段的预订须严格遵循以下模式之一:(a) **连续天数**(连续日期,最多5天);或 (b) **每周重复**(同一星期几,间隔7天,最多12周)。不接受重复日期或不规则组合;此类情形下租用方须分别进行预订,并仍受时长上限及其他限制的约束。

2.3. **可预订时间窗口。** 每个预订时段须完全落在空间提供方就该星期几所公布的闲置时间窗口内,且不得落在空间提供方已屏蔽的日期内。

2.4. **按天计价。** 若空间提供方提供按天(整个班次)计价,则当该价格比按小时计价对租用方更有利时,自动适用于6小时或以上的预订时段。

2.5. **规避限制的企图。** 禁止拆分预订、使用第三方账户、创建多个账户,或以获得持续占用为目的将同一空间提供方旗下多个空间的预订进行组合。此类行为构成违反规则,可能构成转租或不当使用,并适用《处罚与措施》文件规定的后果。

## 3. 明确禁止的使用方式

3.1. 租用方在任何情况下不得:
- (a) 将该空间地址用作**总部、分支机构、税务住所、通讯地址**,或在专业注册、卫生注册、商业注册或宣传材料中将其列为自己的营业场所;
- (b) 在空间内或建筑物上设置**永久性招牌、标识或标志**(在预订时段期间设置、结束时拆除的临时标识,如经空间提供方授权,则允许);
- (c) **过夜**、居住、睡眠或将该空间用作住所(即便是临时性的);
- (d) 在各次预订之间**存放个人物品、材料、设备、病历档案或库存**,但空间提供方在房源信息中明确提供并依其条件使用的寄存服务除外;
- (e) **转租、转让、出借**该空间,或允许未申报的第三方使用该空间;
- (f) 从事与申报不同的活动、空间提供方禁止的活动,或自身不具备法定资质的活动;
- (g) 在预订时段之外接收信件、快递或访客;
- (h) 进行装修、改造、粉刷、安装或布局变更。

3.2. 违反本条使租用方承担违反规则、未经授权活动或转租等相应处罚,此外,在法律允许的情况下,未来的预订时段可被取消且不予退款。

## 4. 预订类型

4.1. **即时预订。** 若房源信息设置为即时预订,则预订在付款授权完成后立即确认,若要求担保人,则须在担保人接受后确认。

4.2. **申请制预订。** 在其他情形下,预订状态为"等待空间提供方确认",款项仅被授权(未扣款)。空间提供方有 **24小时** 时间接受或拒绝。逾期未回复的,申请**自动失效**,授权款项全额释放。拒绝不得基于歧视性标准。

4.3. **需担保人的预订。** 若房源信息要求担保人,预订状态为"等待担保人确认",直至担保人接受为止,担保人有 **48小时** 时间回应(见《担保人与押金》文件)。担保人拒绝或未回应的,申请无偿终止。

4.4. **预订状态。** 预订可处于以下状态之一:等待担保人确认;等待空间提供方确认;已确认;使用中(已完成入场登记);已完成;租用方取消;空间提供方取消;已拒绝;已过期;或未到场(*no-show*)。

## 5. 清洁间隔(缓冲期)

5.1. 空间提供方可设定以分钟计的准备与清洁间隔,该间隔在每个预订时段前后自动锁定。任何其他预订均不得与该间隔重叠。

5.2. 该间隔不向租用方收费,且**不授权**租用方提前到达或延迟离场。超出规定时间停留构成退场延迟(见《处罚与措施》)。

## 6. 时区

6.1. 一切与预订、取消、入场登记、退场登记相关的时间,以及与预订时段开始时刻相关联的期限,均以**空间时区**表示和计算(例如America/Sao_Paulo、America/Manaus、Europe/Lisbon、Asia/Tokyo),包括夏令时转换期间。

6.2. 平台在显示时间的同时显示对应时区。身处其他时区的租用方须自行核实空间当地时间。

## 7. 活动申报与人数

7.1. 在每次预订中,租用方须申报:(a) 其将从事的**活动**(例如"牙科临床诊疗,不含外科手术操作"、"个体心理治疗会谈"、"面向20名学生的授课");以及 (b) 同时在该空间内的**人数**,包括其本人、助理及终端客户。

7.2. 人数不得超过房源信息中标明的容纳人数。活动须与空间类别相符,并符合空间提供方设定的允许及禁止活动范围、建筑物规定以及法律规定。

7.3. 当实际从事的活动与申报内容不符时,空间提供方可拒绝申请或提起事件登记。

## 8. 专业注册

8.1. 当空间提供方将房源信息标注为**"要求专业注册"**时,只有经平台**验证**专业注册资格的租用方方可完成预订。主管机构因类别及国家而异(例如巴西的CRO、CRM、CRP、OAB、CREFITO、CRN或CRMV;英国的GDC、GMC或HCPC;墨西哥的cédula profesional/SEP;澳大利亚的Ahpra),具体依《各国规则》文件规定。

8.2. 租用方声明其注册资格处于有效状态、未被暂停,且涵盖所申报的活动。任何暂停、吊销或限制情形须立即告知,在此期间禁止使用要求该注册资格的空间。

8.3. 即使房源信息未要求注册资格,租用方仍须对其从事活动所需的法定资质承担唯一责任。

## 9. 空间的个人使用

9.1. 预订具有属人性质。空间仅可由预订的租用方本人及其申报的人员(助理、终端客户、学生、参与者)在申报人数范围内使用。租用方对以其名义预订进入该空间的所有人员的行为负责。

9.2. 当租用方为法人时,须指明将到场的负责专业人员,该人员须满足房源信息中规定的专业注册要求。

## 10. 入场登记与退场登记

10.1. **门禁。** 完整地址及进入指引仅在预订确认后公开。

10.2. **入场登记。** 到达时,租用方须在平台上办理入场登记,并建议对空间及设备状况拍摄带日期时间戳的照片。发现的异常情况(不洁、损坏、设备故障)须在开始使用前报告,建议在15分钟内完成,以免被归咎于租用方。

10.3. **退场登记。** 结束时,租用方须将空间恢复至接收时的状态,关闭设备,按指引关闭窗户和门,归还钥匙或门卡,并办理退场登记,建议附带照片。

10.4. **准时性。** 租用方不得在开始时间之前进入,也不得在结束时间之后停留。结束后有10分钟宽限期;超过该时间即适用《处罚与措施》规定的退场延迟收费。

10.5. **未到场。** 若租用方既未到场也未取消,该预订时段将被标记为未到场,该预订时段的基础价值**不予退款**。

10.6. **无法进入。** 若租用方因空间提供方原因无法进入空间,须通知空间提供方,并在24小时内提起"无法进入"事件登记;事实经核实后,受影响预订时段的费用将全额退还。

## 11. 预订变更

11.1. 日期、时间或人数的变更可通过平台提出申请,须经空间提供方同意、视是否有空档而定,并须符合本文件规定的所有限制。差价将被收取或退还。减少时长视为部分取消,适用取消政策。

## 12. 最终规定

12.1. 预订时接受的空间规范(房源信息内部规定)及建筑物或物业管理规定构成本文件的组成部分。

12.2. 对本规则的疑问可发送至 [E-MAIL DE CONTATO](联系邮箱)。
