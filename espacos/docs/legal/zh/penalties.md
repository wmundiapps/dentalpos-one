# 处罚与措施

版本 2026-09-24 · 自2026年9月24日起生效

## 1. 目的与原则

1.1. 本文件为《使用条款》的组成部分,规定对违反本条款、《预订与使用规则》、《行为与尊重空间规范》或某房源信息内部规定的租用方和空间提供方,适用的金钱处罚、警告及其他措施。

1.2. 各项处罚遵循**比例原则、合理性原则、辩论原则及充分抗辩权**。除通过退场登记自动记录的退场延迟收费(该项收费同样可被质疑)外,任何收费均须以事件登记、证据及给被指控方回应机会为前提。

1.3. 各项处罚具有补偿性违约金及对损失的合理预估的性质。在法律允许的情况下,不排除对已证实的超额损失进行赔偿,但不得就同一事实重复处罚。

## 2. 适用于租用方的处罚表

2.1. 金额相对于事实发生所在的预订进行计算。"基础价值"指该次预订各预订时段按小时或按天计价之和,不含各项费用。

| 违规行为 | 参考处罚 | 警告 | 空间提供方报告期限 |
|---|---|---|---|
| **退场延迟**(*overstay*) | 10分钟宽限期;超过后,按15分钟为单位,每单位按小时价格的1.5倍收费;若延迟超过30分钟,所有单位均按小时价格的2倍收费(见第3条),并须赔偿受影响的下一位租用方 | 否(重复发生可能构成违反规则的警告) | 24小时 |
| **额外清洁** | 经证实的额外清洁成本 | 否 | 24小时 |
| 对空间、家具或设备造成的**损坏** | 经证实的维修或更换成本(见第4条) | 否,除非属故意或重大过失造成的损坏 | 72小时 |
| **违反**空间、建筑物或平台**规则** | 基础价值的20% | 是 | 72小时 |
| **超出容纳人数**(人数多于申报或容纳上限) | 基础价值的25% | 是 | 72小时 |
| **未经授权的活动**(与申报不符、被空间提供方禁止或无相应资质) | 基础价值的50% | 是 | 72小时 |
| **转租**或转让给第三方 | 基础价值的100%;可能导致账户被除名 | 是——严重违规 | 168小时(7天) |
| 在空间内**吸烟或使用违禁物质** | 相当于该空间小时价格2小时的金额,另加专业清洁成本(如有) | 是 | 24小时 |
| 因租用方原因导致的**物业管理/建筑物罚款** | 转付实际处以的罚款金额,凭通知书副本 | 是 | 720小时(30天) |
| **骚扰或歧视** | 账户除名;不影响法律责任的追究 | 是——严重违规 | 720小时(30天) |
| **平台之外的付款**(要求、提供或接受) | 相关各方账户除名 | 是——严重违规 | 720小时(30天) |
| **未到场** | 丧失该预订时段基础价值(适用取消政策);不另收罚款 | 否 | 24小时 |

2.2. 报告期限自事实发生的预订时段结束时起算;对于物业管理罚款,则自该罚款所涉预订时段结束时起算。对于事实此前无法知悉的情形(例如隐蔽性损坏),经平台说明理由,逾期报告的事件可例外予以受理。

## 3. 退场延迟——计算规则

3.1. 延迟时间自预订时段结束时刻起,至实际退场登记时刻(平台登记、空间提供方的门禁记录或其他适当证据)止计算。

3.2. 计算方式:
- (a) 延迟不超过 **10分钟**:不收费(宽限期);
- (b) 延迟超过10分钟且不超过 **30分钟**:总延迟时间按 **15分钟** 为单位向上取整,每个单位按小时对应价格的 **1.5倍** 收费;
- (c) 延迟超过 **30分钟**:总延迟时间按15分钟为单位向上取整,每个单位按小时对应价格的 **2倍** 收费。

3.3. 示例(以每小时价格100为例):

| 延迟时间 | 15分钟单位数 | 倍数 | 收费 |
|---|---|---|---|
| 8分钟 | — | — | 0 |
| 20分钟 | 2 | 1.5倍 | 75 |
| 30分钟 | 2 | 1.5倍 | 75 |
| 40分钟 | 3 | 2倍 | 150 |
| 60分钟 | 4 | 2倍 | 200 |

3.4. 若延迟导致其他租用方的预订时段受阻或缩短,延迟方须承担对**受损租用方的赔偿**,金额以平台向其退还的数额为限,若属重复发生,还可能被记录违反规则的警告。

## 4. 损坏与额外清洁

4.1. 租用方对因自身、其助理、终端客户及访客的作为或不作为造成的损害负责,正常使用产生的自然损耗除外。

4.2. 空间提供方须证明:(a) 此前状态(房源信息中的照片、入场登记照片、维护记录);(b) 损坏或污损情况(带日期时间戳的照片或视频);(c) 相应成本(至少一份独立供应商报价单、发票或收据)。对于设备,以维修成本为准,若维修不可行,则以经合理折旧后的同类设备市场价值为准。

4.3. 当空间需要超出常规范围的清洁时(例如未妥善处置的生物废弃物、污渍、过量垃圾),应支付额外清洁费用。

## 5. 程序

5.1. **提起。** 事件通过争议解决中心在报告期限内提起,须附描述、证据及请求金额。

5.2. **答复。** 被指控方接到通知后,有 **48小时** 时间接受、抗辩或提出方案,并可提交己方证据。保持沉默可被视为同意,但不免除平台对证据进行审查的义务。

5.3. **裁决。** 平台以说明理由的方式作出裁决,可减轻、维持或撤销处罚,并决定是否记录警告。可依《争议解决中心》文件在7日内提出申诉。

5.4. **扣款顺序。** 经确认或裁定的款项按以下顺序扣收:
- (1) 仍然有效的**预授权押金**;
- (2) 租用方注册的**支付方式**;
- (3) **担保人**,以其责任限额为限。

5.5. 若欠款仍未清偿,平台可暂停账户直至清偿完毕,并采取法律允许的催收措施,但未依适用法律规定事先通知不得将其列入违约名单。

5.6. 因损坏、额外清洁、物业罚款、延迟及百分比处罚收取的款项,转付给空间提供方(或适用情形下的受损租用方),仅扣除适用情形下的支付处理成本。

## 6. 警告制度

6.1. 警告在 **12个月(365天)** 滚动窗口内累计:

| 过去12个月内的警告次数 | 后果 |
|---|---|
| 1或2次 | 记录于历史记录并通过电子邮件通知 |
| **3次** | **暂停90天**(视身份不同,无法进行新预订,或无法发布/接受预订) |
| **5次** | **永久除名** |

6.2. **严重违规行为**——转租、骚扰或歧视、平台之外付款及人身安全风险——无论警告次数多少,均可导致**立即除名**。

6.3. 暂停期间,已确认的未来预订可由平台取消,并向无过错一方全额退款。

6.4. 因申诉改判而撤销的裁决所产生的警告将被移除。

## 7. 适用于空间提供方的处罚

| 违规行为 | 后果 | 警告 | 租用方报告期限 |
|---|---|---|---|
| **房源信息不准确**(空间、设备、容纳人数或条件与广告所述有重大差异) | 按损失比例向租用方退款,最高可达受影响预订时段的100%;须整改房源信息 | 是 | 24小时 |
| **无法进入**(空间关闭、无钥匙、被第三方占用) | 向租用方退还该预订时段100%款项 | 是 | 24小时 |
| **安全问题**(人身安全风险、设施不合规、危险设备) | 立即暂停该房源信息;可能被除名 | 是——严重违规 | 72小时 |
| **空间提供方取消** | 按提前量处以基础价值0%、10%或25%的罚款(见取消政策) | 是 | — |
| 骚扰、歧视或平台之外付款 | 除名 | 是——严重违规 | 30天 |

7.1. **12个月内由空间提供方发起的取消达3次**,导致空间提供方账户暂停,适用与第6条相同的警告制度。

7.2. 因空间提供方过错应向租用方支付的退款,从空间提供方的转账中扣除或向其收取。

## 8. 合理性限制与当地法律

8.1. 任何处罚的金额或方式均不得达到适用法律认定为不公平或不成比例的程度。特别是:
- (a) 在**巴西**,须遵守《消费者保护法典》(第39条及第51条)、《民法典》(第413条——违约金的公平减轻)以及禁止明显过度利益的规定;
- (b) 在**澳大利亚**,处罚及取消费用须符合《澳大利亚消费者法》关于不公平合同条款的规则;
- (c) 在**欧盟**及**英国**,须遵守第93/13/EEC号指令及《2015年消费者权利法》关于不公平条款的规定;
- (d) 在其他国家,须遵守《各国规则》文件中列明的消费者及合同法律。

8.2. 当处罚金额相对于预订的性质与目的、各方行为及实际损失明显过高时,平台可依职权减轻处罚。

8.3. 同一预订中各项百分比处罚(违反规则、超出容纳人数、未经授权的活动及转租)之和不得超过基础价值的100%,但不影响对已证实损害及成本的赔偿。

## 9. 保全措施

9.1. 如有严重违规或对人身安全构成风险的迹象,平台可采取保全措施,暂停账户或房源信息,取消未来预订并暂扣相关转账款项,期限以调查所需为限,并通知受影响一方。

9.2. 当存在犯罪迹象、严重职业道德违规或公共健康风险时,平台可在遵守数据保护法律的前提下,通知主管当局,包括专业团体。
