## 2. 定义

2.1. 就本条款及所有附件文件而言,以下首字母大写的术语具有下列含义:

| 术语 | 定义 |
|---|---|
| **平台** | 由运营方运营的 SpaceHour 数字环境(网站、应用程序、API 及各类通讯)。 |
| **运营方** | Instituto Ravel de Ensino Superior Ltda.,负责运营本平台。 |
| **用户** | 在本平台注册的任何自然人或法人。 |
| **空间提供方** | 发布空间房源信息并在其闲置时段将其提供使用的用户。 |
| **租用方** | 预订空间供临时使用的用户,通常为专业人士或企业。该术语系市场惯例用语,不意味着存在租赁合同关系(见第3条)。 |
| **终端客户** | 由租用方在空间内接待的患者、客户、学生、参与者或其他人员。终端客户并非本条款的当事方,但涉及使用可选评价工具的情形除外。 |
| **担保人** | 应租用方请求,在《担保人与押金》文件规定的限度内,为某次预订的财务义务提供担保的成年自然人或法人。 |
| **空间** | 在平台上发布的可直接使用的场所,例如牙科诊所、医疗诊所、心理咨询室、物理治疗室、美容室、营养咨询室或兽医诊所、律师事务所、教室、礼堂、会议室、共享办公空间、工作室、实验室、专业厨房或其他场所,并附有其家具和设备的描述。 |
| **房源信息** | 平台上关于该空间的页面,包含描述、照片、设备、容纳人数、价格、可预订时间、政策及规范。 |
| **预订** | 空间提供方与租用方通过平台订立的合同,由一个或多个预订时段组成。 |
| **预订时段** | 一次预订中,在某一日期内连续使用某空间的每个时间段,具有起止时间(例如,某个每周系列预订中每逢周二的时段)。 |
| **基础价值** | 一次预订中所有预订时段按小时或按天计费价格之和,不含各项费用。 |
| **清洁费** | 由空间提供方设定的每个预订时段的固定费用,上限为基础价值的30%。 |
| **服务费** | 运营方因居间撮合而收取的报酬:由租用方支付基础价值加清洁费总额的12%,并从向空间提供方的转账款项中扣除3%。 |
| **押金** | 在租用方支付方式上进行的预授权(临时冻结),上限为基础价值的3倍,用于担保损害赔偿及处罚款项。 |
| **事件** | 在争议解决中心就某次预订中发生的、可能产生费用、警告或其他措施的事实(例如退场延迟或财物损坏)所提出的正式记录。事件不同于预订时段,后者指预订的时间段本身。 |
| **警告** | 因违规行为而记录在用户历史记录中的记载,其效果依《处罚与措施》文件规定。 |
| **空间时区** | 空间所在城市的官方时区,一次预订的所有时间均以该时区表示。 |

## 3. 空间提供方与租用方之间关系的法律性质

3.1. 预订构成**对配备设施的空间的临时使用许可(转让)**,按确定的小时、班次或天数,用于事先申报的专业活动。预订**不构成不动产租赁合同**,不构成非住宅、商业或企业租赁,不构成租赁经营权转让、长期无偿借用或占有权转让。

3.2. 租用方仅获得在约定的预订时段内进入并停留于该空间、使用房源信息中所述家具及设备的属人的、不可转让的、可随时撤销的权利。空间提供方始终保持对该空间的占有、保管和控制。

3.3. 在巴西,预订不适用第8,245/1991号法律(《租赁法》),**不产生商誉或"商业场所权"**,不赋予该法所规定的续约诉权、优先权、无理由或有理由终止通知权,也不产生任何自动续期。在其他司法辖区,适用相同的理解,以相应的法律概念对应(例如英国法上的"占用许可"(licence to occupy)、西语国家的"服务提供/使用权转让合同"、德国法上的"使用协议"(Nutzungsvereinbarung)),不产生承租人保护、续约或稳定居住等权利。

3.4. 为维持该法律性质,平台对时长、频率和提前预订时间设定了限制(见《预订与使用规则》文件),各方不得予以排除,包括:每个预订时段最长12小时,须在06:00至23:00之间,不得过夜;最长连续5天;每周重复预订最多12周;同一租用方就同一空间在30天滚动窗口内的使用上限为120小时。

3.5. 禁止租用方将该空间地址用作总部、分支机构、税务住所、通讯地址、专业或卫生注册地址,禁止设置永久性招牌或实施任何表明持续占用的行为。违反本条款将触发《处罚与措施》文件规定的措施,并不影响损害赔偿请求权。

3.6. 租用方对其在该空间内向终端客户提供的服务承担唯一的技术和专业责任。空间提供方与租用方之间,以及二者与运营方之间,均不构成雇佣、合伙、联营、社团、代理、特许经营或合作关系。
