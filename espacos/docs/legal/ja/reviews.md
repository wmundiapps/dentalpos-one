# レビューポリシー

バージョン 2026-09-24 · 2026年9月24日施行

## 1. 目的

1.1. 本書類は利用規約に組み込まれるものであり、本プラットフォーム上に公開されるレビューを規律する。レビューは、実際の経験に基づき、ホストと利用者(Locatário)との間の信頼を醸成するために存在する。

1.2. レビューには次の3種類がある。
- (a) **利用者(Locatário)がスペースおよびホストを評価する**
- (b) **ホストが利用者(Locatário)を評価する**
- (c) **エンドクライアントがスペースを評価する** — **任意**の機能であり、利用者(Locatário)の希望による場合にのみ有効化される

## 2. 評価できる者および期限

2.1. 完了した予約(最後の予約枠のチェックアウトまたは終了があったもの)の当事者のみが、予約ごとに1回、相互に評価することができる。

2.2. 評価の期限は、予約終了後**14日間**とする。

2.3. 各レビューには、1から5つ星の総合評価、各項目ごとの1から5の評価、および**10文字から2,000文字**の公開コメントが含まれる。相手方のみに向けた非公開の評価を含めることもでき、これは公開されない。

## 3. 評価項目

3.1. **利用者(Locatário)がスペースおよびホストを評価する場合。**

| 項目 | 評価内容 |
|---|---|
| 清潔さ | 到着時のスペースの衛生状態 |
| 正確性 | 掲載情報と実際の状態との一致度 |
| 設備 | 掲載された設備の有無、動作状況および保守状態 |
| 立地 | 住所のアクセス、安全性および利便性 |
| コミュニケーション | ホストの明確さおよび対応の速さ |
| コストパフォーマンス | 料金と体験内容の適合性 |

3.2. **ホストが利用者(Locatário)を評価する場合。**

| 項目 | 評価内容 |
|---|---|
| 時間厳守 | 予約時間どおりの到着および退出 |
| 丁寧さ | スペースおよび設備の保全および清潔さの維持 |
| 規則の遵守 | スペース、建物および本プラットフォームの規則の遵守 |
| コミュニケーション | 明確さおよび礼儀正しさ |
| 推薦するか | 他のホストに当該利用者(Locatário)を推薦するかどうかの「はい/いいえ」の表示 |

## 4. 双方向匿名評価

4.1. ホストと利用者(Locatário)の間のレビューは**双方向匿名(ダブルブラインド)**方式で行われる。いずれの当事者も、自らのレビューを送信するまでは相手方のレビューを見ることができない。両方のレビューは、両当事者が評価を終えた時点、または14日の期限が終了した時点のいずれか早い方で公開される。

4.2. 公開後、レビューは、本プラットフォームへの申請による事実誤認の訂正を除き、投稿者による編集を行うことができない。

## 5. 公開返信

5.1. 評価された者は、受け取った各レビューに対して**1件の公開返信**を投稿することができ、これには内容に関する同じ規則が適用される。返信は客観的でなければならず、個人攻撃や第三者の個人データを含んではならない。

## 6. エンドクライアントによるレビュー(任意)

6.1. **有効化。** 利用者(Locatário)は、**希望する場合**、あるエンドクライアントのスペースに関するレビュー収集を予約について有効化することができる。ホストはこの有効化を要求することができない。

6.2. **招待。** 利用者(Locatário)は、それぞれ**14日間**有効な**使い捨てリンク**を、予約ごとに**最大50件**まで生成し、任意の方法でエンドクライアントに渡す。本プラットフォームは、この目的のためにエンドクライアントの連絡先情報を受け取ることはない。

6.3. **匿名性。** エンドクライアントによるレビューは**匿名**である。登録を必要とせず、氏名や識別情報は表示されず、投稿者は任意のニックネームのみを示すことができる。

6.4. **評価項目。** エンドクライアントは、**スペース**のみを、**快適さ、清潔さ、アクセシビリティおよび立地**の各項目について評価する。専門家(利用者(Locatário))、対応または受けた施術内容は評価対象としない。

6.5. **健康データの禁止。** エンドクライアントによるレビューに、**健康データ、診断、治療、処置**、氏名、身分証明書、連絡先、または患者、顧客もしくは受診理由を特定し得る情報を含めることは**禁止**される。フォームにはこの注意事項が表示され、この規則に違反するレビューは削除される。

6.6. **職業上の守秘義務。** 利用者(Locatário)は、自らの職業倫理に照らして、招待の交付が施術の守秘義務と両立するか(例:心理相談業務の場合)を判断しなければならず、その判断について単独で責任を負う。リンクの交付は、何らかの利益と引き換えに行うことも、患者を露出させる方法で行うこともできない。

6.7. **表示。** エンドクライアントによるレビューは、その旨を明示した上で別途表示され、スペース独自の指標を構成する。

## 7. コンテンツに関する規則

7.1. レビューは、正直で、実際の経験に基づき、予約に関連するものでなければならない。次の内容を含むレビューは禁止される。
- (a) 第三者の個人データ、健康データまたは機密情報を含むもの
- (b) 差別的、攻撃的、わいせつ、脅迫的な内容、または嫌がらせに該当するもの
- (c) ヘイトスピーチまたは暴力の扇動を含むもの
- (d) 広告、外部リンクまたは連絡先情報を含むもの
- (e) 予約に無関係の事実、または関与していない第三者に言及するもの
- (f) 意図的に虚偽であるか、誤解を招くもの

## 8. 虚偽のレビュー、買収されたレビューおよび恐喝

8.1. 次の行為は禁止される。(a) 予約に参加していないのに評価すること、(b) レビューまたはその削除と引き換えに支払い、割引、返金または利益を提供もしくは受け取ること、(c) レビューを生成するために架空の予約を作成すること、(d) 複数のアカウントを使用すること、(e) 利益を得る目的で**ネガティブレビューの投稿を脅迫の材料とすること**(恐喝)、または正当なインシデントを開設した者に対してネガティブレビューで報復すること、(f) エンドクライアント用の招待を生成し、これを自ら、または対応を受けていない者に入力させること。

8.2. これらの行為は重大な違反であり、違反者は警告の対象となり、場合により削除の対象となるほか、関連するレビューも削除される。

## 9. モデレーションおよび削除

9.1. 本プラットフォームはレビューの内容を編集することはないが、本書類、法律または裁判所の決定に違反するレビューの全部もしくは一部を**削除**すること、または不正行為により取り消された予約に関連するレビューを非表示にすることができる。

9.2. いかなる利用者も、本プラットフォームを通じてレビューを通報することができる。審査は合理的な期間内に行われ、削除された場合は投稿者に通知され、投稿者は異議を申し立てることができる。

9.3. 本プラットフォームは、単に否定的であるという理由だけでレビューを削除することはない。意見の相違は公開返信を通じて対処されるべきである。

9.4. インシデントの対象となっている予約に関するレビューは、報復を避けるため、決定が下されるまで非表示のまま保持されることがある。

## 10. レビューの利用

10.1. 平均評価は、公開されたレビューから算出され、プロフィールおよび掲載情報に表示される。レビューは検索結果の順位付けや表彰プログラムにおいて考慮されることがある。

10.2. 透明性に関する規則(欧州連合のデジタルサービス法(Regulamento de Serviços Digitais)や消費者保護法など)を遵守し、本プラットフォームは、実際に完了した予約の当事者、および有効な招待リンクを有するエンドクライアントのみが評価できることを明らかにする。
