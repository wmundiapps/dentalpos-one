# 予約・利用規則

バージョン 2026-09-24 · 2026年9月24日施行

## 1. 目的

1.1. 本書類は利用規約に組み込まれるものであり、本プラットフォームにおける予約の実施、確定および利用の方法を規律する。大文字で始まる用語は、利用規約に定める意味を有する。

1.2. 本プラットフォームは、**すぐに利用できるスペースを、その空き時間に時間、シフトまたは日単位で共同利用すること**を可能にするために存在する。本プラットフォームは、継続的な占有、長期の賃貸借、事業所在地または居住のための手段ではない。

1.3. 本書類に定める制限は、予約の時点でシステムにより自動的に適用されるものであり、**ホストと利用者(Locatário)との間の合意によっても排除することができない**。これらの制限は、次の目的のために設けられている。(a) 設備付きスペースの一時使用許諾としての性質を維持し、賃貸借としての性格付けおよび営業権もしくは更新権の取得を排除すること(ブラジルにおいてはLei nº 8.245/1991、他国においては同等の規則)。(b) スペースへの多様な専門家の回転利用および利用機会を確保すること。(c) 占有または恒久的な使用の主張からホストを保護すること。

## 2. 時間および期間の制限

2.1. 次の制限がすべての予約に適用される。

| パラメータ | ルール |
|---|---|
| 時刻の単位 | 開始・終了時刻は**30分**単位(例:08:00、08:30、09:00) |
| 予約枠ごとの最短時間 | **1時間**、またはホストが掲載情報で定めるこれより長い最短時間 |
| 予約枠ごとの最長時間 | **12時間** |
| 利用可能時間帯 | スペースの時間帯における**06:00**から**23:00**の間 |
| 宿泊 | **禁止** — 各予約枠は同日内に開始および終了すること |
| 連続日数 | 同一予約内で最大**5日連続** |
| 週次反復 | 1シリーズ(同一曜日)につき最大**12週間** |
| 予約あたりの予約枠数 | 最大**12** |
| 事前予約可能な最長期間 | スペースの時間帯における現在日から**180日** |
| 事前予約に必要な最短期間 | 予約枠開始の**1時間**前まで |
| 時間数の上限 | 利用者(Locatário)ごと・スペースごとに、任意の**30日間**の移動期間で**120時間** |

2.2. **認められるパターン。** 複数の予約枠を含む予約は、次のいずれかのパターンに厳密に従わなければならない。(a) **連続日**(連続する日付、最大5日間)、または(b) **週次反復**(同一曜日、7日間隔、最大12週間)。重複した日付や不規則な組み合わせは認められない。この場合、利用者(Locatário)は別個の予約を行わなければならず、当該予約も時間数の上限その他の制限の適用を受ける。

2.3. **空き時間枠。** 各予約枠は、ホストが当該曜日について提示する空き時間枠のいずれかに完全に収まらなければならず、ホストがブロックした日付にかかってはならない。

2.4. **日額料金。** ホストが日額料金(フルシフト)を提示している場合、6時間以上の予約枠であって、時間単価よりも利用者(Locatário)にとって有利であるときは、当該日額料金が自動的に適用される。

2.5. **制限の回避の試み。** 予約の分割、第三者のアカウントの使用、複数アカウントの作成、または同一ホストの複数のスペースにまたがる予約の組み合わせにより、継続的な占有を得ようとすることは禁止される。かかる行為は規則違反を構成し、転貸または不適正利用に該当し得るものとし、ペナルティおよび措置に定める結果を招く。

## 3. 明示的に禁止される利用

3.1. 利用者(Locatário)は、いかなる場合であっても次の行為を行うことができない。
- (a) スペースの住所を、自己の事業所であるかのように**本店、支店、税務上の住所、通信用住所**、専門職登録上、衛生登録上もしくは商業登録上の住所、または広告素材における住所として使用すること
- (b) スペースまたは建物に**恒久的な看板、標識または表示**を設置すること(予約枠の間の一時的な表示であって、終了時に撤去されるものは、ホストが許可した場合には認められる)
- (c) **宿泊**すること、居住すること、就寝すること、または一時的であってもスペースを住居として使用すること
- (d) ホストが掲載情報において明示的に提供し、その条件に従う荷物預かりサービスを除き、**予約と予約の間に私物、資材、設備、カルテまたは在庫を保管する**こと
- (e) 申告されていない第三者に対してスペースを**転貸、譲渡、貸与**し、またはその利用を許可すること
- (f) 申告した活動と異なる活動、ホストが禁止する活動、または法的に許可を有しない活動を行うこと
- (g) 予約枠の時間外に郵便物、配達物または訪問客を受け取ること
- (h) 工事、改修、塗装、設備の設置またはレイアウトの変更を行うこと

3.2. 本条項への違反は、場合に応じて、規則違反、無許可の活動または転貸に関するペナルティの適用対象となり、これに加えて、法律が許容する場合には、将来の予約枠の返金なしの取消しの対象となる。

## 4. 予約の種類

4.1. **即時予約。** 掲載情報が即時予約として設定されている場合、予約は決済の承認後、また保証人が必要な場合はその承諾後、直ちに確定する。

4.2. **申請制予約。** その他の場合、予約は「ホスト回答待ち」の状態となり、金額は承認(オーソリ)されるのみで確定的な請求は行われない。ホストは承諾または拒否のため**24時間**を有する。この期間内に回答がない場合、申請は**自動的に失効**し、承認は全額解放される。拒否は差別的な基準に基づくことができない。

4.3. **保証人を伴う予約。** 掲載情報が保証人を要求する場合、予約は保証人による承諾があるまで「保証人回答待ち」の状態となり、保証人は回答のため**48時間**を有する(保証人・保証金に関する書類参照)。保証人による拒否または無回答は、費用の発生なく申請を終了させる。

4.4. **予約の状態。** 予約は次のいずれかの状態を取り得る。保証人回答待ち、ホスト回答待ち、確定済み、利用中(チェックイン済み)、完了、利用者(Locatário)によるキャンセル、ホストによるキャンセル、拒否、失効、または不出頭(ノーショー)。

## 5. 清掃時間(バッファー)

5.1. ホストは、各予約枠の前後に自動的にブロックされる準備・清掃時間を分単位で設定することができる。この時間帯には他の予約を重ねることができない。

5.2. この時間は利用者(Locatário)に課金されず、利用者(Locatário)が開始時刻前に到着し、または終了時刻後に退出することを**許可するものではない**。設定時間を超えて滞在することは、退出遅延を構成する(ペナルティおよび措置参照)。

## 6. タイムゾーン

6.1. 予約、キャンセル、チェックイン、チェックアウトに関するすべての時刻、および予約枠の開始に紐づく期限は、夏時間の切り替えを含め、**スペースの時間帯**(例:America/Sao_Paulo、America/Manaus、Europe/Lisbon、Asia/Tokyo)により表示および計算される。

6.2. 本プラットフォームは時刻とともにタイムゾーンを表示する。異なるタイムゾーンにいる利用者(Locatário)は、スペースの現地時刻を自ら確認する責任を負う。

## 7. 活動内容および人数の申告

7.1. すべての予約において、利用者(Locatário)は次の事項を申告する。(a) 実施する**活動内容**(例:「外科処置を伴わない歯科臨床診療」、「個人心理療法セッション」、「20名の生徒を対象とする授業」)、(b) 自己、アシスタントおよびエンドクライアントを含め、スペースに同時に存在する**人数**。

7.2. 人数は掲載情報に示された収容人数を超えることができない。活動内容は、スペースのカテゴリー、ホストが定める許可・禁止活動、建物の規則および法令に適合していなければならない。

7.3. 実際に行われた活動が申告内容と異なる場合、ホストは申請を拒否し、またはインシデントを開設することができる。

8.1. ホストが掲載情報に**「専門職登録が必要」**である旨を表示している場合、本プラットフォームにより登録が**確認済み**である利用者(Locatário)のみが予約を完了することができる。所管機関は、カテゴリーおよび国によって異なる(例:ブラジルにおけるCRO、CRM、CRP、OAB、CREFITO、CRNまたはCRMV、英国におけるGDC、GMCまたはHCPC、メキシコにおけるcédula profesional/SEP、オーストラリアにおけるAhpra)。詳細は国別規則に定める書類を参照する。

9.1. 予約は一身専属である。スペースは、予約の名義人である利用者(Locatário)および同人が申告した人物(アシスタント、エンドクライアント、生徒、参加者)のみが、申告された人数の範囲内で利用することができる。利用者(Locatário)は、自己の予約の下でスペースに入場するすべての者の行為について責任を負う。

## 10. チェックインおよびチェックアウト

10.1. **アクセス。** 完全な住所およびアクセス方法の案内は、予約確定後にのみ開示される。

10.2. **チェックイン。** 到着時、利用者(Locatário)は本プラットフォームでチェックインを登録し、スペースおよび設備の状態について日時入りの写真を記録することが推奨される。不備(汚れ、損傷、設備の不具合など)がある場合は、これらが自己に帰属させられないよう、利用開始前、望ましくは15分以内に報告しなければならない。

10.3. **チェックアウト。** 利用終了時、利用者(Locatário)は、スペースを受け取った状態に戻し、設備の電源を切り、案内に従って窓や扉を閉め、鍵やカードを返却し、望ましくは写真とともにチェックアウトを登録しなければならない。

10.4. **時間厳守。** 利用者(Locatário)は開始時刻前に入場すること、または終了時刻後に滞在することができない。終了後10分間の猶予があり、これを超えるとペナルティおよび措置に定める退出遅延に係る課金が発生する。

10.5. **不出頭。** 利用者(Locatário)が出頭せず、かつキャンセルもしない場合、当該予約枠は不出頭として記録され、当該予約枠の基本料金は**返金されない**。

10.6. **アクセス不能。** ホストの事由により利用者(Locatário)がスペースにアクセスできない場合、利用者(Locatário)はホストに連絡し、24時間以内に「アクセス不能」に関するインシデントを開設しなければならない。当該事実が証明された場合、影響を受けた予約枠について全額返金を受ける。
